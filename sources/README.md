# sources/

Put each original game in its own folder, named after the game:

```
sources/
├── gorilla/        GORILLA.BAS and anything that came with it
├── nibbles/
└── ...
```

Tips:

- Keep the files exactly as you found them (original names, extensions, docs).
- If you know where it came from (magazine issue, book, disk, website),
  add a short `ORIGIN.txt` in the game folder. One line is enough.
- This folder is read-only for coding agents. They read it, never change it.
