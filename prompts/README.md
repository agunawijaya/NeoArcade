# prompts/

Build prompts for Claude Code, written by the architect after the design
for a game is agreed.

Naming: `NNN-<game>-<step>.md`, for example:

- `000-bootstrap-hall.md` — set up the Arcade Hall and shared pieces
- `001-gorilla-port.md` — first full build of a game
- `002-gorilla-polish.md` — follow-up fixes and polish

To run one, open Claude Code in `E:\Projects\NeoArcade` and say:

> Read prompts/001-gorilla-port.md and do it.
